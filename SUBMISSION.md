## Submission checklist

1. Submit the live website URL.
2. Submit the live backend API URL.
3. Submit the public GitHub repository URL.
4. Submit the API documentation URL.
5. Include the three demo accounts so each role can be evaluated.
6. If the submission form supports attachments, add screenshots of the home page and the three role dashboards.

Do not submit `.env`, `DATABASE_URL`, `JWT_SECRET`, or any other secret.
